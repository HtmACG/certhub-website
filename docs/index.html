快速开始 ​

CertHub 是完全免费的 SSL 证书自动化管理系统：申请、DNS 验证、部署、监控与续期全部编排进一条可视化流水线，不含任何数量限制。

三步跑通第一条流水线 ​

1. 配置授权 ​

进入 授权管理 → 新建授权，选择类型（云厂商 / 主机 / 面板 / 证书签发），把凭据填进去，点「测试」确认能连通。

你的场景该建哪种授权
域名托管在阿里云 / 腾讯云 / Cloudflare对应的云厂商授权（用 DNS-01 验证）
要部署到自己的服务器主机 SSH 授权
要部署到宝塔 / 1Panel / 群晖对应的面板授权
用 Google Trust Services / FreeSSL 签发EAB 凭据（证书签发分类）

凭据在数据库里 AES-GCM 加密存储，界面上的密码框默认显示星号，点右侧「小眼睛」可查看明文 —— 这是刻意设计，方便排障时确认到底填了什么。

2. 创建流水线 ​

证书流水线 → 新建流水线，两种起步方式：

  • 从模板创建：内置 8 套模板（Let's Encrypt + Nginx / SSH / 阿里云 CDN / 腾讯云 CDN / HTTP 验证 / 火山引擎 + CDN / 仅申请 / 自签测试），套用后补域名与授权即可。
  • 空白创建：自己加阶段与任务，适合流程比较特殊的场景。

一条典型的流水线包含三个阶段：

阶段 1 申请证书   →  CertApply（选 CA、填域名、选 DNS 授权）
阶段 2 部署证书   →  DeployToNginx / DeployToHost / 云 CDN …
阶段 3 通知       →  Notify（选通知渠道）

3. 手动运行一次 ​

点右上角 运行（有未保存改动时按钮会变成「保存并运行」）。画布下方的日志坞会逐行实时输出执行过程，失败的任务整张卡片标红，并给出中文原因。

跑通之后：

  1. 打开 证书库，确认新证书已入库（域名、签发机构、剩余天数）。
  2. 打开 定时任务，设成每天凌晨跑一次 —— 之后到期前会自动续期，不用再管。
  3. 在 通知渠道 里配一个机器人或邮件，续期失败时能第一时间收到。

首次登录

默认账号 admin / 123456，登录后请立刻在 账号安全 里改密码，并建议开启两步验证。

界面地图 ​

侧边栏按「流程」分组，第一次用按这个顺序走一遍即可：

分组页面作用
概览工作台流水线、有效证书、运行成功率、站点状态、主机资源

接入资源DNS 记录托管在平台里的解析记录（手动申请时用）
接入资源站点监控定时巡检站点证书，到期前告警
接入资源通知渠道邮件、Webhook、钉钉 / 飞书 / 企微机器人等
系统系统设置站点信息、网络代理、安全策略、到期提醒
系统用户管理账号、用户组与功能权限
