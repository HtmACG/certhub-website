技术栈 ​

层选择
后端Python 3.11+ / FastAPI / SQLAlchemy 2 / SQLite（可切 PostgreSQL、MySQL）
调度APScheduler（定时流水线、站点巡检、到期提醒）
密码学cryptography（密钥、CSR、证书解析、PFX / P7B 导出）
ACME自研 ACME v2 客户端（JWS 签名、订单、挑战、EAB）
远程执行paramiko（SSH / SFTP）
前端React 19 + Vite 6 + TypeScript + Tailwind CSS v4 + shadcn/ui 风格组件
状态与路由TanStack Query + react-router-dom 7（HashRouter，兼容后端静态托管）

元数据驱动 ​

新增签发方式 / 部署目标 / DNS 服务商 / 通知渠道，只改后端 plugins.py 的注册表：

注册表作用
TASK_PLUGINS任务插件（申请 / 部署 / 通知）及其表单字段
ACCESS_TYPES授权类型及其表单字段
NOTIFY_TYPES通知渠道及其字段
ACME_PROVIDERSCA 名称、目录地址、是否要 EAB

前端表单、授权下拉、任务选择器、概览页的「支持的证书」全部由这些元数据自动生成，不要在前端硬编码插件清单。

字段的敏感属性由 component == "password" 声明，不靠字段名猜。字段还可以声明动作按钮（action），例如群晖的「获取设备 ID」。

主要接口 ​

所有业务接口返回统一信封：{ code, msg, data }，鉴权用请求头 Authorization: <token>。

接口说明
POST /api/auth/login登录，返回 token / refreshToken
GET /api/auth/captcha图形验证码（失败次数达到阈值后要求）
GET /api/pipeline/plugins任务插件元数据
GET /api/pipeline/list流水线列表（分页）
GET /api/pipeline/templates模板列表
POST /api/pipeline/from-template按模板创建
POST /api/pipeline/{id}/run运行，立即返回 historyId
POST /api/pipeline/{id}/stage/run单独运行某个阶段
POST /api/pipeline/batch批量运行 / 启停 / 改定时 / 删除
GET /api/history/{id}/streamSSE 实时日志（历史记录则回放）
POST /api/history/{id}/stop协作式停止
GET /api/access/options?types=a,b授权下拉（按精确类型过滤）
POST /api/access/{id}/test测试授权连通性
POST /api/access/synology/device-id换取群晖受信设备令牌
GET /api/cert/list证书库
POST /api/cert/import导入自有证书
GET /api/cert/{id}/download导出 PEM / DER / PFX / P7B / JKS / Nginx
GET /api/monitor/site/list站点监控列表
GET /api/settings系统设置（site / security / notify / network）
GET /api/health健康检查（异常返回 503）

开放接口 ​

给脚本 / CI 用的独立命名空间，用 API 密钥鉴权（不用 JWT）：

bash
curl -H "x-api-key: ck_xxx" -H "x-api-secret: yyy" \
     http://127.0.0.1:8000/api/open/v1/pipelines

curl -X POST -H "x-api-key: ck_xxx" -H "x-api-secret: yyy" \
     http://127.0.0.1:8000/api/open/v1/pipelines/7/run

curl -H "x-api-key: ck_xxx" -H "x-api-secret: yyy" \
     http://127.0.0.1:8000/api/open/v1/certs
接口说明
GET /api/open/v1/pipelines列出流水线
POST /api/open/v1/pipelines/{id}/run触发运行
GET /api/open/v1/certs最近 100 张证书
GET /api/open/v1/certs/{id}单张证书详情

密钥管理（创建 / 删除）走登录态接口 /api/open/keys，secret 只在创建时返回一次。

前端开发 ​

bash
cd webui
npm install
npm run dev      # http://localhost:5174，/api 代理到 127.0.0.1:8000
npm run build    # 产物 webui/dist
npm run deploy   # 构建并复制到 ../frontend/dist（后端托管的目录）

目录约定：src/components/ui 是设计系统，src/components/layout 是外壳与导航，src/features/<域> 按页面拆分，src/lib 放 http、类型与 SSE 日志 hook。

冒烟测试 ​

后端启动后跑接口冒烟（覆盖鉴权、分页、插件一致性、加密、限速等断言）：

bash
python tests/smoke.py --base http://127.0.0.1:8000 --user admin --password 123456

新增插件、改了注册表、动了引擎之后都应该跑一遍再提交。
