更新日志 ​

1.0.0 — 2026-11-04 ​

首个对外版本，包含完整的证书自动化链路。

证书签发 ​

  • 自研 ACME v2 客户端：JWS 签名、订单、DNS-01 / HTTP-01 挑战、EAB、证书链选择
  • 6 家 ACME CA：Let's Encrypt、Google Trust Services、ZeroSSL、FreeSSL / LiteSSL、Buypass、自定义 ACME
  • 云厂商免费证书：阿里云、腾讯云、火山引擎；商业 CA：TrustAsia
  • 本地自签与自有证书导入（校验 PEM 与密钥配对）
  • 导出 PEM / DER / PFX / P7B / JKS / Nginx

流水线 ​

  • 阶段 + 任务三层模型，画布拖拽连线、失败后跳转、未接入任务、阶段摆位
  • 实时日志（SSE）、协作式停止、历史回放、阶段与任务级日志过滤
  • 8 套模板、批量运行 / 启停 / 改定时 / 删除、cron 定时任务
  • 75 个部署插件：主机、面板、集群、云 CDN、对象存储与通用任务

资源与监控 ​

  • 41 种授权类型，按精确类型校验；授权「测试」真登录一次
  • 群晖 DSM 受信设备 ID（自动回退验证码）
  • 站点监控、到期提醒、10 种通知渠道（含业务码校验）

系统 ​

  • React 19 + Tailwind v4 重写的前端（HashRouter，单端口部署）
  • 用户组权限、登录提醒、审计日志、开放接口（API 密钥）
  • TOTP 两步验证、登录失败锁定、图形验证码、安全响应头
  • 在线备份与恢复脚本、健康检查、Docker 部署

后续计划 ​

  • 更多厂商的部署插件（面板 / 国内 CDN 长尾）
  • 证书链与密钥的批量轮换
  • 更细粒度的用户组权限
